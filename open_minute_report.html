How to read this, and what is assumed

  • First minute: the 1-minute candle stamped 09:15, covering 09:15:00 to 09:15:59. Bars before 09:15 (the pre-open session) are ignored.
  • ATM and distance: ATM is the index's 09:15 open rounded to the strike interval found in each expiry file. Distance is how far the strike sits beyond ATM, as a share of the index, so the three indices and different years can be compared. Only out-of-the-money strikes up to 5% away are kept.
  • Previous close: the last traded price of the same contract in the previous session, and for the index and India VIX the last 1-minute close of the previous session. These can differ slightly from the exchange's official closing prices.
  • Which expiries: on each day, the 2 nearest expiries. Days to expiry are calendar days to the expiry date in the file name.
  • Small premiums: options that opened below 1 points are left out of every statistic, because one tick (0.05) is a large percentage of such a price. Medians are used throughout for the same reason.
  • Only what traded: a strike appears on a day only if it traded in the 09:15 minute. Far strikes that did not trade are missing, so far-strike figures describe the liquid ones.
  • India VIX: no VIX file was found in the dataset's index/ folder and none was passed with --vix-file, so the VIX charts are missing.
  • Correlation is not cause: the index gap, India VIX and option prices all react to the same overnight news. The charts show what moved together, not what drove what.
