    Refresh button setup

    Refresh asks GitHub to re-run the scan now (1–2 minutes). It needs a GitHub token, which is stored only in this browser.

    1. Open GitHub → Fine-grained tokens → Generate.
    2. Repository access: Only select repositories → open-labs.
    3. Permissions: Actions: Read and write and Contents: Read-only. Nothing else.
    4. Generate, copy and paste it here.

    No token? Run it from GitHub → “Run workflow”.
